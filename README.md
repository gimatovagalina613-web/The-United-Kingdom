# Oops! English! — UK Puzzle

Interactive English learning game: match the countries of the United Kingdom, their capitals and flags. Supports drag and drop, touch and keyboard controls.

## Play online

Enable GitHub Pages in **Settings → Pages → Deploy from a branch → main → / (root) → Save**.

## Run locally

Serve this folder with a static web server, for example `python -m http.server 8000`, then open http://localhost:8000.

Country boundaries: ONS / Ordnance Survey; source credit is included in the game. Flags: FlagCDN. Fredoka font: SIL Open Font License, see assets/Fredoka-OFL.txt.
